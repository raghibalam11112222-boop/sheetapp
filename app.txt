You are a senior SaaS product engineer, product designer, database architect, and security engineer.

Build a production-quality SaaS called **SheetApp**.

## PRODUCT

SheetApp transforms business spreadsheets into usable internal business applications.

Core promise:

> **Turn the spreadsheet your business depends on into a real internal app.**

A user uploads an Excel/CSV file. The system analyzes the spreadsheet, understands its structure, detects relationships and business fields, and generates a working internal application with:

* Database
* Dashboard
* Tables
* Search
* Filters
* CRUD operations
* Forms
* Basic permissions
* AI-generated schema
* Data validation
* Basic workflows

Do NOT position this as a generic AI app builder.

The product is specifically for businesses that currently operate important workflows through Excel/Google Sheets.

# 25. SECURITY

Perform a security-first implementation.

Requirements:

* Server-side validation
* Authentication on protected routes
* Authorization checks
* Secure database queries
* Rate limiting on expensive endpoints
* File type validation
* File size limits
* Malware-safe file handling where applicable
* Never execute uploaded spreadsheet formulas
* Prevent formula injection on export
* Sanitize user-generated content
* Prevent SQL injection through ORM
* Protect against XSS
* CSRF protection where applicable
* No secrets in frontend
* Secure error messages
* Audit sensitive operations

Uploaded spreadsheets are untrusted input.

Treat them as malicious until validated.
