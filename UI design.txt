# SheetApp — UI/UX Design

## 1. Design Direction

Style:

**Minimal + Premium + Professional**

Visual references:

* Modern SaaS
* Subtle glassmorphism
* Clean enterprise software
* Apple-like simplicity

Avoid:

* Excessive gradients
* Neon colors
* Huge typography
* Over-animation
* Clutter
* Generic AI-dashboard appearance

## 2. Color System

Use a neutral foundation.

```text
Background:        #F8F9FA
Surface:            #FFFFFF
Primary Text:       #111111
Secondary Text:     #6B7280
Border:             #E5E7EB
Primary Action:     #111111
Success:            #16A34A
Warning:            #D97706
Danger:             #DC2626
```

Dark mode can be added later.

## 3. Typography

Use:

**Inter**

Hierarchy:

```text
H1: 48–64px
H2: 32–40px
H3: 24px
Body: 15–16px
Small: 13–14px
```

Keep typography clean and restrained.

## 16. UX Principles

### Progressive disclosure

Don't show advanced functionality until needed.

### Clear actions

Primary actions should always be obvious.

### Feedback

Every important action should provide feedback.

### Safety

Destructive actions require confirmation.

### Trust

Always show what the AI detected before creating the application.

### Simplicity

The user should never need to understand:

* databases
* schemas
* APIs
* SQL

The product should handle that complexity.

## 17. Core UX Goal

A first-time user should be able to go from:

```text
"I have an Excel file"
```

to:

```text
"I have a working business application"
```

with as little friction as possible.

Target:

**Upload → Review → Generate → Use**
